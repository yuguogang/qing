# 清谱项目 LLM Wiki 操作规则

## 1. 基本原则
- `raw/` 目录为只读原始素材，**禁止修改**，仅可读取和新增
- 优先更新现有 Wiki 页面，**禁止随意新建页面**（除非没有相关主题）
- 所有内容必须引用原始素材路径，关键结论需标注来源
- 不确定的内容标记为「待补充/疑问」，禁止作为确定结论

## 2. 目录结构
```
llm-wiki/
├── raw/                    # 原始素材层（只读）
│   ├── tech-research/      # 技术调研资料
│   ├── competitor-analysis/ # 竞品分析
│   └── ip-legal/           # 知识产权/法律
├── wiki/                   # 结构化知识层
│   ├── overview.md         # 全局概览
│   ├── glossary.md         # 术语表
│   ├── concepts/           # 概念页
│   ├── entities/           # 实体页
│   ├── decisions/          # 决策记录
│   └── incidents/          # 故障/风险
├── prompt/                 # LLM 操作提示词
├── diff/                   # 待审核的修改
├── report/                 # 校验报告
└── AGENTS.md               # 本文件
```

## 3. 摄入规则 (Ingest)
- 新素材放入 `raw/` 对应目录，命名格式：`日期_主题_来源.md`
- 摄入时优先匹配已有 Wiki 页面，更新而非新建
- 生成的 diff 放入 `diff/` 目录，等待人工审核

## 4. 页面模板
```markdown
---
title: 【页面主题】
status: draft/ready/review
source_count: 【引用原始素材数量】
last_reviewed: 【最后审核日期】
---

## 摘要
（1-2句话概括）

## 核心内容
（结构化撰写）

## 引用来源
（原始素材路径）

## 关联页面
（[[页面名称]] 链接格式）

## 待补充/疑问
```

## 5. 校验规则
- 每周执行一次 Wiki 健康检查
- 检查引用来源完整性
- 检查页面关联合理性
- 检查内容一致性（无矛盾）
- 生成校验报告到 `report/`

## 6. 禁止事项
- 禁止删除任何 Wiki 页面（标记为「废弃」即可）
- 禁止在 Wiki 页面中硬编码未经验证的技术结论
- 禁止跳过引用来源标注
