# 术语表

| 术语 | 英文 | 释义 |
|------|------|------|
| 三色锚线 | Three-Color Anchor Lines | 在五线谱上选定三条关键线条（高音谱表：下加一线C、第三线B、上加一线A），以不同颜色标记，作为识谱的视觉锚点 |
| 锚线识谱法 | Anchor Line Sight-Reading | 以三条彩色锚线为基准，利用对称推导逻辑快速定位全谱音高的识谱方法 |
| 浅雅七色谱 | Seven-Color Chromatic Mode | 进阶模式，对七个音级分别赋予不同颜色，覆盖全线条分层上色 |
| MusicXML | MusicXML | 音乐记谱的行业标准交换格式，基于 XML，被主流乐谱软件支持 |
| mscz | MuseScore Compressed | MuseScore 原生格式，本质为 zip 压缩包内含 mscx（XML）+ 媒体资源 |
| OSMD | OpenSheetMusicDisplay | 基于 VexFlow 的浏览器端 MusicXML 渲染引擎 |
| VexFlow | VexFlow | JavaScript 乐谱渲染库，支持 SVG/Canvas 输出 |
| alphaTab | alphaTab | 跨平台乐谱渲染库，主攻吉他谱，MusicXML 支持为实验性 |
| Web MIDI API | Web MIDI API | W3C 标准 API，允许网页与 MIDI 设备通信 |
| 复音检测 | Polyphonic Pitch Detection | 同时检测多个音高的音频分析技术，钢琴场景核心难点 |
| 自相关算法 | Autocorrelation | 单音音高检测的经典算法，精度可达 ±0.5Hz |
| 视觉拥挤效应 | Visual Crowding | 五线谱线条密集导致初学者辨识困难的认知心理学现象 |
| 中央C | Middle C (C4) | 钢琴键盘中央位置的 C 音，五线谱识谱的核心锚点 |
| 加线 | Ledger Line | 五线谱上下方临时添加的短线条，用于记录超出五线范围的音 |
| 瀑布流 | Waterfall/Cascade | Simply Piano 等产品使用的音符下落式可视化方式 |
