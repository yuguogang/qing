# 三色锚线知识产权风险

## 背景
原 plan.md 将三色锚线描述为项目「独家核心壁垒」和「原创设计」。经调研发现，该设计已有版权登记。

## 风险识别

### 已确认事实
- **原创者**: 郑锡勇
- **版权登记号**: 粤作登字-2026-A-00000644
- **登记类别**: 美术作品（视觉设计）
- **公开宣传**: 已在今日头条等平台发布多篇宣传文章

### 原计划逻辑错误
1. **IP 归属不清**: plan.md 暗示三色锚线为项目原创，但实际为第三方已登记版权
2. **法律风险低估**: 未提及授权/合规问题，直接使用可能构成侵权
3. **「全网唯一」表述风险**: 宣称「全网唯一正统彩色锚线五线谱产品」可能引发 IP 纠纷

## 修正方案

### 方案A: 获取授权（推荐）
- 与郑锡勇达成商业授权协议
- 明确授权范围（Web/APP/印刷）
- 在项目中明确标注「三色锚线识谱法由郑锡勇原创」

### 方案B: 设计差异化方案
- 采用不同的颜色标注逻辑（如：同色同音法，每个音级固定颜色）
- 锚线数量和位置差异化
- 确保不侵犯已登记的视觉设计方案

### 方案C: 确认项目关联
- 如本项目即为郑锡勇本人的项目，需在 plan.md 中明确说明
- 补充版权登记信息，增强可信度

## 建议
**在推进开发前，必须先明确 IP 归属和授权关系**，这是项目合规的前置条件。
