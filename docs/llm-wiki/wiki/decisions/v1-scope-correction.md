# V1.0 范围与工期修正

## 原计划问题

### 1. 工期严重低估
原 plan.md 声称：
- 极速验证版 15 天
- 商用上线版 25-30 天
- 成本 5000-15000 元

**修正评估**：
| 模块 | 原计划工期 | 修正工期 | 原因 |
|------|-----------|---------|------|
| 云端转谱服务 | 5-8天 | 7-10天 | Docker 封装 + 队列 + 存储 |
| 前端乐谱渲染 | 未单独估算 | 10-15天 | OSMD 集成 + 三色锚线定制 + 交互 |
| MIDI 纠错 | 1周 | 7-10天 | Web MIDI + 匹配算法 + UI |
| 账号体系 | 未单独估算 | 3-5天 | Supabase Auth + 权限 |
| 曲库管理 | 未单独估算 | 5-7天 | 分类/搜索/收藏 |
| **总计** | 25-30天 | **35-50天** | 原计划遗漏多个模块的工期 |

### 2. 成本严重低估
- 5000-15000 元无法覆盖专业前端 + 后端 + 音频工程师的人力成本
- 修正估算：按 1-2 名全栈工程师，合理成本为 30000-60000 元
- 如外包，市场价至少 50000-100000 元

### 3. V1.0 功能范围过大
原 V1.0 包含：
- ✅ 公版三色锚线曲库
- ✅ mscz 上传转谱
- ✅ MIDI 跟弹纠错
- ✅ 三色谱模式开关/缩放/打印
- ✅ 账号体系 + 会员权限
- ⚠️ 变速伴奏、分手练习、小节循环（应拆到 V1.1）

**修正建议**：V1.0 砍掉「打印功能」和「会员权限分级」，聚焦核心练琴闭环。

### 4. 麦克风识别定位不准
原计划将麦克风识别列为 V2.0，但描述中暗示「准确率可达行业主流水平」。
**修正**：钢琴复音识别是行业难题，不应承诺「行业主流水平」。V2.0 仅做单音跟弹场景。

## 修正后的 V1.0 范围
1. 公版三色锚线曲库（5-10 首内置曲目）
2. 前端 OSMD 三色锚线渲染 + 滚动跟弹
3. MIDI 连接 + 实时对错标注
4. 基础变速 + 分手练习
5. 基础账号体系（登录/注册）
