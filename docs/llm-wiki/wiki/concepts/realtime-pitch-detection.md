# 实时拾音纠错系统

## 摘要
清谱项目的双通道识音纠错方案：MIDI 蓝牙连接（精准）+ 麦克风音频拾音（便捷），对标 Simply Piano 核心陪练能力。

## 双通道架构

### 通道1: MIDI 连接（推荐优先）
- **协议**: Web MIDI API (`navigator.requestMIDIAccess()`)
- **延迟**: < 5ms，几乎无感
- **精度**: 100% 准确（直接读取按键数据）
- **兼容性**: Chrome/Edge 完整支持，Firefox 需手动开启，Safari 不支持
- **数据**: Note On/Off + Velocity + Channel

### 通道2: 麦克风拾音
- **技术栈**: Web Audio API + AnalyserNode
- **算法选择**:
  - 自相关算法：单音检测，精度 ±0.5Hz
  - FFT + 谐波匹配：复音检测，精度受限
  - poly-peach (WASM)：针对特定音符的复音检测
- **挑战**: 钢琴泛音丰富，多键叠加时频谱复杂
- **可行场景**: 已知旋律的模板匹配（跟弹场景）

## 纠错逻辑
1. 获取当前期望音符（从乐谱数据中读取）
2. 接收实际输入（MIDI 或麦克风）
3. 对比匹配：正确 → 绿色标记 / 错误 → 红色标记
4. 记录错音数据，生成演奏评分

## 配套功能
- 单小节循环练习
- 全局变速（0.5x ~ 2.0x）
- 左右手分手练习
- 内置节拍器
- 演奏评分与复盘

## 实现优先级
| 阶段 | 功能 | 说明 |
|------|------|------|
| V1.0 | MIDI 连接 + 纠错 | 体验最佳，技术成熟 |
| V2.0 | 麦克风单音检测 | 覆盖无 MIDI 设备用户 |
| V3.0 | 麦克风复音检测 | 和弦识别，技术难度高 |
