# Simply Piano

## 摘要
全球领先的钢琴学习 APP，由 JoyTunes 开发。核心特征为游戏化闯关 + 音频听音识别，用户基数大但存在「会弹不识谱」的核心缺陷。

## 核心特征
- **技术**: 麦克风拾音 + 音高检测算法
- **谱面**: 弱化五线谱，瀑布流音符为主
- **模式**: 游戏化闯关，渐进式难度
- **商业**: 订阅制（~$10/月 或 $70/年）
- **用户**: 全球数千万下载，以零基础/儿童为主

## 与清谱的错位关系
| 维度 | Simply Piano | 清谱 |
|------|-------------|------|
| 谱面 | 弱化五线谱 + 瀑布流 | 正统五线谱 + 三色锚线 |
| 目标 | 快速弹曲 | 练琴即识谱 |
| 纠错 | 音频识别为主 | MIDI + 音频双通道 |
| 用户留存 | 依赖游戏化 | 依赖识谱能力提升 |
| 能力迁移 | 脱离软件不会弹 | 可迁移到纸质谱视奏 |

## 可借鉴点
1. 音频识别降低设备门槛（但清谱 V1.0 先做 MIDI）
2. 游戏化提升用户粘性（清谱 V3.0 考虑）
3. 渐进式课程设计（清谱可参考其难度曲线）
