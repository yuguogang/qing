# VexFlow

- **类型**: 实体
- **类别**: 乐谱渲染引擎（底层库）
- **相关**: [[OSMD]], [[乐谱渲染引擎对比]]

## 基本信息

| 属性 | 值 |
|------|-----|
| 定位 | 底层五线谱渲染库 |
| 协议 | BSD |
| 渲染 | 原生 SVG / Canvas |
| 社区 | 活跃 |

## 核心能力

1. 底层五线谱元素精确绘制（音符、符干、谱号、小节线等）
2. 完全可控的样式定制（颜色、尺寸、位置）
3. 高度灵活的 API，可构建任意复杂乐谱布局

## 关键限制

- **无内置 MusicXML 解析**：需手动构建乐谱数据结构
- **无内置播放**：纯渲染库，不含音频
- **上手门槛高**：需手动管理所有乐谱元素

## 与清谱的关系

OSMD 基于 VexFlow 构建，通过 `EngravingRules` 等 API 间接使用 VexFlow 的渲染能力。清谱的三色锚线、七色谱等功能依赖 VexFlow 底层的样式定制能力。
