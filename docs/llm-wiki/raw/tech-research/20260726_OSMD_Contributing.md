# OSMD Contributing - 原始素材

来源: https://github.com/opensheetmusicdisplay/opensheetmusicdisplay/wiki/Contributing

## 贡献流程

1. 查看 [Issues](https://github.com/opensheetmusicdisplay/opensheetmusicdisplay/issues)（含已关闭的），确认想法是否已被讨论
2. 提交新 Issue 或 Pull Request

## 合并策略

- PR 通常先合并到 feature branch
- 打磨和充分测试后才合并到 develop
- develop 有重大更新时合并到 master 并发布
- master 打 tag 后发布到 [NPM](https://www.npmjs.com/package/opensheetmusicdisplay)

## 规范

- 无严格的 Issue/PR 模板
- 遵循常识性的礼貌和尊重行为准则
