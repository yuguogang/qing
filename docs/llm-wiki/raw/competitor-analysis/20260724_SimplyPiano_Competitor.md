# 竞品分析：Simply Piano & 钢琴练琴 APP 市场

- 来源: 公开信息、产品官网
- 日期: 2026-07-24
- 状态: 已验证

## Simply Piano

### 核心特征
- **技术路线**: 音频听音识别 + 游戏化闯关
- **谱面**: 弱化五线谱，使用瀑布流音符
- **商业模式**: 订阅制（月/年费）
- **用户画像**: 零基础入门、儿童启蒙
- **核心优势**: 音频识别（麦克风即可）、游戏化体验
- **核心缺陷**: 用户会弹不识谱，脱离软件无法视奏

### 技术架构（推测）
- 音频识别: 麦克风拾音 + 音高检测算法
- 前端: 瀑布流音符下落 + 键盘高亮
- 曲库: 授权流行曲 + 原创教程

## 其他竞品

### Flowkey
- 视频教学 + 实时纠错
- 支持 MIDI + 麦克风
- 谱面为标准五线谱但无颜色辅助

### Piano Marvel
- 专业级五线谱教学
- 支持 MIDI 连接
- 面向院校/机构

### 完美钢琴 (Perfect Piano)
- 国内产品，虚拟键盘 + 瀑布流
- 偏娱乐化，非专业教学

## 市场空白
- **无产品** 做「正统五线谱 + 三色视觉锚点 + 交互式练琴」
- 现有产品要么弱化五线谱（Simply Piano），要么无颜色辅助（Flowkey）
- 清谱定位精准：填补「识谱练琴一体化」赛道空白
