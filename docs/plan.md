三色锚线谱交互式练琴APP详细开发方案（清谱版）
一、项目核心概述
### 1.1 项目核心定位
本项目主打国内首款三色锚线标准五线谱交互式练琴产品——清谱。彻底区别于Simply Piano等传统练琴软件，不走"弱化五线谱、游戏化快速弹曲"的轻量化入门路线，聚焦全年龄段（特别是成人自学、琴行教学）核心痛点：识谱难、记谱难、脱离软件不会识谱、上下加一线认音卡顿。
产品核心逻辑： 保留正统完整五线谱结构，仅通过三色视觉锚点优化识谱体验，实现"练琴即识谱"。让用户在日常跟弹练习中建立永久识谱记忆，打通软件练琴与纸质乐谱视奏的能力迁移。清谱是刚需型系统学琴工具，而非碎片化娱乐闯关工具。
### 1.2 与Simply Piano核心错位关系
二者为互补赛道、非竞品，底层逻辑完全相反，规避正面竞争，同时可承接Simply Piano海量用户的识谱短板需求：
*   Simply Piano： 核心优势为音频听音纠错、游戏化闯关陪练，核心缺陷是弱化标准五线谱、依赖瀑布流音符，用户短期会弹琴、长期不识谱，学琴进阶必卡壳，识谱功能为附属配套；
*   清谱： 核心优势为标准化识谱教学体系、可视化锚线谱面渲染，核心能力是练琴+识谱一体化，弥补行业产品空白，陪练纠错为配套基础能力，精准解决学琴核心痛点。
### 1.3 项目核心价值与市场优势
打破行业"二选一"困境（要么弱化五线谱、要么纯黑白无辅助），抢占正统彩色锚线五线谱交互式练琴蓝海赛道，兼具C端刚需属性与B端教学适配性，用户日活、留存、付费意愿远高于单纯乐谱转谱工具，商业化闭环更稳固。
二、整体产品架构与核心功能设计
产品以交互式识谱练琴为核心，乐谱转谱为配套入口，搭建"曲库练习-自定义转谱-实时跟弹纠错-专项识谱训练-云端存储"完整闭环，整体分为四大核心功能模块。
### 2.1 核心差异化功能：三色锚线可视化乐谱系统（清谱核心壁垒）
为产品独家核心壁垒，所有练琴页面实时渲染，无需导出PDF即可可视化使用，支持双模式一键切换，适配不同学习阶段用户：
*   三色锚线基础模式（默认）： 锁定中央C核心锚点，对五线谱第三线、上下加一线关键识谱线条做专属色彩标记，解决找音慢、记不住跨区音符、加线音符识别难的问题，所有色彩优化基于正统五线谱结构，不改变谱面标准格式，兼容纸质乐谱；
*   浅雅七色谱进阶模式： 进阶识谱训练使用，全线条分层上色，适配长期系统学琴用户，强化音阶、音区记忆；
*   配套能力： 支持锚线颜色自定义开关、谱面缩放、高清打印，完美适配居家练琴、课堂视奏、纸质谱练习场景。
### 2.2 对标行业顶配的交互式练琴体系
全面复刻Simply Piano核心练琴能力，同时叠加识谱优势，实现功能持平、体验差异化升级：
*   双渠道识音纠错： 支持MIDI电钢蓝牙连接、手机麦克风原声钢琴拾音，适配全用户设备场景；
*   精细化练琴交互： 实时对错音符标注、单小节循环、全局变速伴奏、左右手分手练习、内置精准节拍器、演奏评分复盘；
*   沉浸式滚动乐谱： 练琴全程保留彩色锚线，乐谱自动滚动，无需用户频繁暂停找音，保障演奏流畅度。
### 2.3 双曲库乐谱供给体系
覆盖用户所有练琴乐谱需求，实现"开箱即练、自定义随心练"：
*   公有标准曲库： 预录入拜厄、车尔尼599/849、哈农基础教程，以及热门流行钢琴曲，全部预渲染三色锚线谱，分类清晰、点开直接练琴，无需二次处理；用户可点击收藏喜欢的曲目至个人私有云端曲库，打开即练。
*   私有云端曲库： 支持用户自主上传mscz格式乐谱，云端自动转换为三色锚线谱或浅雅七色谱，绑定个人账户云端存储，多端同步、随时调用。
### 2.4 专属识谱训练模块
实现练琴与识谱教学一体化，解决传统练琴软件"只练不教、只会弹不会认"的问题：开发锚线认音专项习题、音区识别训练、加线音符专项练习，训练进度与日常练琴数据绑定，针对性弥补识谱短板，逐步建立标准化五线谱识谱思维。
三、核心技术开发方案（低难度、高落地性）
整体开发无需修改MuseScore底层C++源码，采用"云端转译+前端自主渲染"轻量化方案，规避开源版权风险、降低开发成本，全程适配网页端、移动端APP，分为四大技术模块落地。
### 3.1 模块一：云端MuseScore转谱渲染服务（基础配套，中等难度）
*   核心功能： 实现用户mscz乐谱上传、云端自动解析、批量转换三色锚线SVG/PDF格式，配套任务队列、云端存储、个人账户数据隔离，保障转谱稳定、数据安全。
*   开发逻辑： 复用成熟MuseScore解析内核，搭建云端自动化转谱服务。用户上传乐谱后，系统自动排队处理，生成带三色锚线的标准化乐谱文件，存入个人云盘，支持在线预览、练琴调用、高清打印。
*   开发工期： 5-8天。
*   ⚠️ 可行性点评： 此方案成熟可靠。关键在于处理好并发任务队列，避免用户上传高峰时服务器阻塞。建议使用Docker封装MuseScore环境，便于迁移和扩容。
### 3.2 模块二：交互式彩色五线谱渲染（核心难点，中等难度）
为清谱核心技术壁垒，提供两套落地方案，优先推荐自主可控方案，兼顾上线速度与长期迭代空间。
*   推荐方案（长期商用首选）：alphaTab / OSMD 前端引擎渲染
    *   技术逻辑： 云端将用户上传的mscz文件统一转译为标准MusicXML格式，下发至网页/APP前端，通过alphaTab、OSMD开源乐谱引擎自主绘制五线谱。
    *   核心定制开发： 写入专属渲染逻辑，自动识别中央C对应线条、上下加一线，实现关键线条自动上色、锚点标记，保留完整五线谱结构。
    *   适配功能： 原生支持乐谱滚动、音符高亮、跟弹标记、缩放自适应，完美适配所有交互式练琴场景。
    *   核心优势： 完全自主可控，无GPL开源版权限制，网页、APP多端通用，可后续迭代更多识谱交互功能，AI可辅助完成前端定制代码开发。
*   ⚠️ 可行性点评（重点）： 这是整套方案中最正确的一步。 放弃修改MuseScore源码，改用OSMD/alphaTab是前端的明智之举。这两个引擎专门用于在浏览器和App中渲染MusicXML，性能极佳。你需要重点攻克的是"如何在不破坏谱面布局的情况下覆盖线条颜色"，这通常可以通过Canvas/SVG图层叠加来实现，技术风险低。
### 3.3 模块三：实时拾音/MIDI练琴纠错系统（中等难度）
对标Simply Piano核心听音陪练能力，复用成熟开源音频方案，低成本实现全功能复刻，稳定性高、延迟低。
*   MIDI蓝牙连接： 采用成熟开源蓝牙适配方案（如Web MIDI API），支持电钢、MIDI键盘实时连接，低延迟识别按键音高、节奏，精准标记对错音符。
*   麦克风音频识别： 复用开源音频处理库（如Essentia或Meyda的JS端口），适配原声钢琴无设备练琴场景，环境噪音过滤、音符识别准确率可达行业主流水平。
*   配套交互功能： 错音标红提示、演奏进度实时同步、小节循环录制、速度调节、节拍器适配、演奏数据评分，整体功能1周可完成开发调试。
*   ⚠️ 可行性点评： MIDI连接几乎无延迟，体验很好。麦克风识别在钢琴这种泛音丰富的乐器上是有挑战的（复音识别），但对于"跟弹纠错"这种已知旋律的匹配场景（模板匹配），准确率是可以接受的。建议初期重点优化MIDI体验，麦克风作为补充。
### 3.4 模块四：账号体系与多端适配（低难度）
采用市面标准化成熟方案，无技术难点，快速落地基础运营能力：
*   用户体系：手机号注册登录、账号密码找回、会员权限分级、个人中心。
*   云端存储：个人乐谱云盘、练琴进度缓存、多端数据同步。
*   曲库管理：公版曲库分类检索、搜索筛选、收藏下载。
*   终端打包：网页端、安卓APP、iOS APP封装适配，兼容主流系统版本。

## 一、项目核心概述

### 1.1 项目核心定位

本项目主打国内首款三色锚线标准五线谱交互式练琴产品——清谱。彻底区别于Simply Piano等传统练琴软件，不走"弱化五线谱、游戏化快速弹曲"的轻量化入门路线，聚焦全年龄段（特别是成人自学、琴行教学）核心痛点：识谱难、记谱难、脱离软件不会识谱、上下加一线认音卡顿。

产品核心逻辑：保留正统完整五线谱结构，仅通过三色视觉锚点优化识谱体验，实现"练琴即识谱"。让用户在日常跟弹练习中建立永久识谱记忆，打通软件练琴与纸质乐谱视奏的能力迁移。清谱是刚需型系统学琴工具，而非碎片化娱乐闯关工具。

## 二、整体产品架构与核心功能设计

产品以交互式识谱练琴为核心，乐谱转谱为配套入口，搭建"曲库练习-自定义转谱-实时跟弹纠错-专项识谱训练-云端存储"完整闭环。

### 2.1 核心差异化功能：三色锚线可视化乐谱系统

为产品独家核心壁垒（合伙人郑锡勇原创，已获版权登记），所有练琴页面实时渲染，支持双模式一键切换：

- **三色锚线基础模式（默认）**：锁定中央C核心锚点，对五线谱第三线、上下加一线关键识谱线条做专属色彩标记。所有色彩优化基于正统五线谱结构，不改变谱面标准格式
- **浅雅七色谱进阶模式**：进阶识谱训练使用，全线条分层上色，适配长期系统学琴用户
- **配套能力**：支持锚线颜色自定义开关、谱面缩放、高清打印

### 2.2 对标行业顶配的交互式练琴体系

- **双渠道识音纠错**：MIDI电钢蓝牙连接（V1.0）、手机麦克风原声钢琴拾音（V2.0，仅单音场景）
- **精细化练琴交互**：实时对错音符标注、单小节循环、全局变速伴奏、左右手分手练习、内置精准节拍器、演奏评分复盘
- **沉浸式滚动乐谱**：练琴全程保留彩色锚线，乐谱自动滚动

### 2.3 双曲库乐谱供给体系

- **公有标准曲库**：预录入拜厄、车尔尼599/849、哈农基础教程，以及热门流行钢琴曲，全部预渲染三色锚线谱
- **私有云端曲库**：支持用户自主上传mscz格式乐谱，云端自动转换为三色锚线谱

### 2.4 专属识谱训练模块（V2.0）

锚线认音专项习题、音区识别训练、加线音符专项练习，训练进度与日常练琴数据绑定。

## 三、核心技术开发方案

### 3.1 模块一：云端MuseScore转谱渲染服务

- **核心功能**：mscz乐谱上传 → 云端MuseScore解析 → MusicXML输出 → 三色锚线元数据注入 → 对象存储
- **技术方案**：Docker 封装 MuseScore CLI + BullMQ 任务队列 + 对象存储
- **修正说明**：原计划描述「复用成熟MuseScore解析内核」表述模糊。实际方案为 MuseScore CLI 命令行转换（`mscore input.mscz -o output.musicxml`），Docker headless 运行（需 Xvfb）
- **开发工期**：7-10天（原计划5-8天偏乐观）
- **版权说明**：MuseScore 为 GPL v3，但仅作为服务端工具使用（不分发），不触发 GPL 传染

### 3.2 模块二：交互式彩色五线谱渲染 [重大修正]

#### ~~原方案~~（已修正）
原 plan.md 将 alphaTab 与 OSMD 并列为推荐方案：「alphaTab / OSMD 前端引擎渲染」

#### 修正后方案：明确选择 OSMD

**选择 OSMD 的理由**：
1. **MusicXML 完整支持**：OSMD 的核心功能就是解析和渲染 MusicXML；alphaTab 的 MusicXML 支持为「实验性」，存在重大风险
2. **钢琴谱核心场景**：OSMD 专为标准五线谱设计；alphaTab 主攻吉他谱/Tab，钢琴五线谱非其核心优化方向
3. **VexFlow 底层定制**：OSMD 基于 VexFlow，提供 `setKeyStyle()` 对单个音符着色、`engravingRules` 控制谱线样式等深度定制能力
4. **BSD 开源协议**：商用友好，无 GPL 限制

**核心定制开发**：
- 通过 VexFlow 的 `setKeyStyle()` 实现音符着色
- 通过 SVG 图层叠加实现特定谱线（第三线、加线）颜色覆盖
- 利用 OSMD 的 `Staves[n].Visible` 实现分手练习
- 基于 OSMD 数据模型实现滚动跟弹的音符高亮同步

**开发工期**：10-15天（原计划未单独估算此核心模块）

### 3.3 模块三：实时拾音/MIDI练琴纠错系统 [修正]

#### 修正点
原计划声称「音符识别准确率可达行业主流水平」，这一表述过于乐观。

**事实**：
- 钢琴是泛音极丰富的乐器，复音识别（和弦）是行业公认难题
- 单音检测（自相关算法）精度可达 ±0.5Hz，满足需求
- 复音检测在已知旋律的模板匹配场景下可接受，但远非「行业主流水平」

**修正后的分阶段方案**：
- **V1.0**：仅 MIDI 连接（Web MIDI API），零延迟、100% 精准
- **V2.0**：麦克风单音检测（自相关算法），覆盖单旋律跟弹场景
- **V3.0**：麦克风复音检测（FFT + 谐波匹配），覆盖和弦场景

**开发工期**：7-10天（V1.0 MIDI部分）

### 3.4 模块四：账号体系与多端适配

- 用户体系：手机号注册登录、会员权限分级
- 云端存储：个人乐谱云盘、练琴进度缓存
- 曲库管理：公版曲库分类检索、收藏

**开发工期**：3-5天
